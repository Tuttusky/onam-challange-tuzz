# Onam Dare Challenge — Campaign Platform

Enterprise-grade viral social dare challenge platform built on Laravel 13 + Vue 3.

## Features

- **Campaign Engine** — Unlimited campaigns (Dare, Quiz, Spin & Win ready via handlers)
- **Vue 3 SPA** — Public game with GSAP, Lottie, Howler
- **Blade Admin** — Full CMS, SEO, analytics, reports, roles
- **Viral Loop** — Create → Share → Challenge → Compare → Repeat
- **Dynamic** — Nothing hardcoded; all content from admin panel

## Stack

Laravel 13 | PHP 8.3+ | MySQL 8 | Vue 3 | Pinia | Bootstrap 5 | Sanctum | Spatie Permission
